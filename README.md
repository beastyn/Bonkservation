# Tempus Bonking Game.

## Features:
1. Brain Designer: designer for AI agents. Includes custom interface, allowing to create behaviours, tasks, indicators and sensors.
2. Implemented few behaviours for Brain Designer.
3. Added shaders for clouds and waaterfall.
4. WIP for gameplay loop.

![Brain Designer UI](https://i.gyazo.com/24cb2e7fb56b4ec2be4ea626dcb0e08a.png)

## Gameplay loop
WIP
1. Play as a manager and look for idols.
2. Bonk idols when they mischieve.
3. Finished mischieve will cause stress.
4. Try to preserve as many days as possible until stress bar is filled up.
